# LOHLAN × Murmur 營運管理系統

這是單頁 HTML 的本機試用版本，包含客戶管理、報價、價目表、月費請款、收款、記帳及客戶追蹤。

## 使用方式

直接用瀏覽器開啟 `index.html`。也可以部署到 GitHub Pages 預覽（僅限測試資料）。

## 重要限制

- 目前資料儲存在瀏覽器本機，**GitHub 不會同步或備份客戶資料**。
- 沒有正式帳號登入、伺服器資料庫、存取權限或安全備份。
- **不要輸入真實客戶個資、財務資料或機密資訊，也不要把真實資料寫入程式碼後推上 GitHub。**
- 正式商用需先加入後端、登入驗證、資料庫、備份與權限控管。

## 上傳 GitHub

1. 建立新的 Private repository，例如 `lohlan-murmur-erp`。
2. 解壓縮本專案，上傳 `index.html`、`README.md`、`.gitignore`。
3. Commit changes。

請勿將真實密碼、API keys 或 `.env` 檔案提交到 GitHub。
